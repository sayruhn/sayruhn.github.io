Sayruhn Studio

Sayruhn Studio is a desktop tool used by the Sayruhn creator to produce short manga-style explainer videos. When a video is finished, the tool uploads it to the creator's own TikTok account as a draft. The creator then opens TikTok, reviews the draft, edits it if needed, and posts it themselves.

How it works

  1. The creator signs in with TikTok (Login Kit) and authorizes the app.
  2. The tool shows which TikTok account is connected (display name and avatar).
  3. Finished videos are sent to TikTok with the Content Posting API (Upload to TikTok, video.upload).
  4. TikTok sends an inbox notification. The creator reviews the draft and decides whether to post.

Sayruhn Studio never publishes anything directly. Every post is made by the creator inside the TikTok app.
